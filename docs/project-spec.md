# Техническое задание проекта STEM

## 1. Название проекта

**STEM — игровой трекер**

## 2. Описание проекта

STEM — это веб-приложение для ведения личной библиотеки видеоигр. Оно позволяет пользователям добавлять игры, собирать собственную коллекцию, оценивать игры, отслеживать прохождение сюжетов и анализировать игровую статистику.

## 3. Целевая аудитория

Приложение предназначено для игроков, которые хотят хранить информацию о своих играх в одном месте, следить за прогрессом прохождения и выбирать следующие игры.

## 4. Проблема пользователя

Игрокам бывает сложно запоминать, какие игры они прошли, сколько времени потратили на прохождение и какие игры им понравились. STEM помогает систематизировать игровую коллекцию и хранить эту информацию в удобном виде.

## 5. Основная сущность

Основная сущность проекта — видеоигра.

### Поля видеоигры

| Поле | Тип данных | Описание |
|---|---|---|
| id | Число | Уникальный идентификатор игры |
| title | Строка | Название игры |
| description | Многострочный текст | Описание игры |
| genre | Строка / категория | Жанр игры |
| releaseYear | Число | Год выхода игры |
| rating | Число | Пользовательская оценка от 0 до 10 |
| playtime | Число | Время, проведённое в игре, в часах |
| status | Строка / категория | Статус прохождения игры |
| favorite | Логическое значение | Добавлена ли игра в избранное |

### Возможные статусы игры

- Не начата.
- В процессе.
- Пройдена.
- Заброшена.

## 6. Действия пользователя

Пользователь сможет:

- Добавлять игры в библиотеку.
- Просматривать подробную информацию об игре.
- Редактировать данные игры.
- Удалять игры из библиотеки.
- Оценивать игры.
- Отмечать игры как избранные.
- Изменять статус прохождения.
- Указывать время, проведённое в игре.
- Искать игры по названию.
- Фильтровать и сортировать библиотеку.

## 7. Страницы приложения

### 7.1. Главная страница

**URL:** `/`

**Назначение:** отображение общей информации о библиотеке.

**Отображаемые данные:** количество игр, недавно добавленные игры, избранные игры и игры в процессе прохождения.

**Действия пользователя:** переход в библиотеку, открытие карточки игры и переход к добавлению игры.

### 7.2. Библиотека игр

**URL:** `/games`

**Назначение:** просмотр и управление всей коллекцией игр.

**Отображаемые данные:** список игр, названия, жанры, оценки и статусы прохождения.

**Действия пользователя:** поиск, фильтрация, сортировка, открытие карточки, редактирование и удаление игры.

### 7.3. Страница добавления игры

**URL:** `/games/new`

**Назначение:** добавление новой игры в библиотеку.

**Отображаемые данные:** форма с полями названия, описания, жанра, года выхода, оценки, времени прохождения и статуса.

**Действия пользователя:** заполнение формы, сохранение новой игры и отмена добавления.

### 7.4. Карточка игры

**URL:** `/games/:id`

**Назначение:** просмотр подробной информации об определённой игре.

**Отображаемые данные:** название, описание, жанр, год выхода, оценка, время прохождения, статус и избранное.

**Действия пользователя:** изменение статуса, переход к редактированию и удаление игры.

### 7.5. Статистика

**URL:** `/statistics`

**Назначение:** анализ игровой активности пользователя.

**Отображаемые данные:** общее количество игр, количество пройденных игр, средняя оценка и общее время прохождения.

**Действия пользователя:** просмотр показателей и переход к соответствующим играм в библиотеке.

### 7.6. Топ игр

**URL:** `/top-games`

**Назначение:** просмотр лучших игр из личной коллекции.

**Отображаемые данные:** список игр с оценками и временем прохождения.

**Действия пользователя:** сортировка по оценке или времени прохождения и открытие карточки игры.

## 8. Пользовательские сценарии

### Сценарий 1. Добавление игры

1. Пользователь открывает страницу добавления игры.
2. Заполняет необходимые поля.
3. Нажимает кнопку сохранения.
4. Приложение добавляет игру в библиотеку.
5. Пользователь видит новую игру в списке.

### Сценарий 2. Редактирование игры

1. Пользователь открывает библиотеку.
2. Выбирает нужную игру.
3. Переходит к редактированию.
4. Изменяет информацию.
5. Сохраняет изменения.

### Сценарий 3. Поиск игры

1. Пользователь открывает библиотеку.
2. Вводит название игры в поле поиска.
3. Приложение отображает подходящие результаты.
4. Пользователь открывает нужную игру.

### Сценарий 4. Отслеживание прохождения

1. Пользователь открывает карточку игры.
2. Изменяет статус прохождения.
3. Указывает время, проведённое в игре.
4. Сохраняет изменения.
5. Обновлённые данные отображаются в библиотеке и статистике.

### Сценарий 5. Просмотр рейтинга

1. Пользователь открывает страницу топа игр.
2. Выбирает сортировку по оценке.
3. Приложение сортирует игры.
4. Пользователь просматривает список лучших игр и открывает их карточки.

## 9. Функции первой версии

В первую версию проекта войдут:

- Просмотр библиотеки игр.
- Добавление, редактирование и удаление игр.
- Поиск по названию.
- Фильтрация по жанру и статусу.
- Сортировка по оценке и времени прохождения.
- Управление статусом прохождения.
- Добавление игр в избранное.
- Просмотр статистики и топа игр.

## 10. Ограничения первой версии

В первую версию не войдут:

- Регистрация и авторизация пользователей.
- Синхронизация данных между устройствами.
- Интеграция с игровыми платформами Steam и Epic Games.
- Автоматическое получение достижений и времени игры.
- Социальная система друзей и совместных коллекций.

## 11. Технологии

- React — создание пользовательского интерфейса.
- TypeScript — типизация кода.
- Vite — запуск и сборка приложения.
- React Router — настройка маршрутов страниц.
- Git — контроль версий проекта.
