# STEM — игровой трекер

## Описание проекта

STEM — это веб-приложение для ведения личной библиотеки видеоигр. Пользователь может добавлять игры, просматривать свою коллекцию, оценивать игры, отслеживать прохождение и анализировать игровую статистику.

## Основные возможности

- Добавление, редактирование и удаление игр.
- Просмотр личной библиотеки.
- Поиск игр по названию и жанру.
- Сортировка и фильтрация игр.
- Отслеживание статуса прохождения и времени игры.
- Просмотр статистики и рейтинга игр.

## Используемые технологии

- React
- TypeScript
- Vite
- React Router
- Git

## Требования

Для запуска проекта необходимы Node.js и npm.

## Установка и запуск

1. Открыть терминал в папке проекта.
2. Установить зависимости:

   `npm install`

3. Запустить режим разработки:

   `npm run dev`

4. Открыть адрес, указанный в терминале.

## Сборка проекта

Для проверки production-сборки выполнить:

`npm run build`
